# Security

Report security issues privately to contacto@tecnobros.es. Include the version, platform, affected component and a minimal reproduction with dummy credentials. Do not post tokens, private keys or production configurations in issues.

The server authorizes tunnel owners; it does not authenticate players joining a public Minecraft port. Configure Minecraft authentication and access rules separately. Application quotas do not replace upstream protection against volumetric attacks.

Keep configuration files private, run the server without root privileges, and restrict the authorization endpoint. Review the limits and certificate renewal schedule before deployment. Use supported Go versions when building releases.
